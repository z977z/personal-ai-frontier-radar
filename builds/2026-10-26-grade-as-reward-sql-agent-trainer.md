# AI Build of the Day

Date: 2026-10-26

中文名：判分即奖励的SQL智能体训练器  
英文名：Grade-as-Reward SQL Agent Trainer  
一句话：用数据库判分器自动生成RL奖励，后训练会写SQL、会自检的数据智能体

## 为什么今天做？

ThinkingBox 展示了数据库判分转 RL 奖励的可行性，且开源模型与 RL 框架已成熟，企业可在自有数据库上低成本复现。

## 实际使用场景

- 企业BI自然语言查询
- 数据仓库ETL脚本生成
- SQL性能优化与纠错
- 数据分析师助手

## Demo

任务采样（问题+目标库）→ 智能体多轮生成SQL/执行/修正 → 沙箱数据库执行 → 判分器比对结果集与执行代价 → 奖励合成（正确性+效率+安全）→ RL后训练（GRPO/PPO）→ 评测与回归

## AI 在里面真正做什么？

智能体负责规划、写SQL、读错误信息并自我修正；判分器提供可验证奖励；教师模型可做蒸馏与冷启动。

## 技术方案

开源基座模型（Qwen/Llama）+ vLLM 推理 + SQLite/Postgres 沙箱 + TRL/verl RL 框架 + 结果集比对判分器

## MVP / 今日目标

今天只完成：单库单表任务集200条，判分器做结果集精确匹配，GRPO 训练一周内跑通，对比基座成功率提升。

- 难度：中
- 预计时间：3-5周
- 预计代码量：约3000-5000行
