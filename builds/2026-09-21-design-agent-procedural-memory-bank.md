# AI Build of the Day

Date: 2026-09-21

中文名：设计智能体程序性记忆库  
英文名：Design Agent Procedural Memory Bank  
一句话：让冻结的前沿模型通过可复用自然语言技能持续进化，无需权重更新。

## 为什么今天做？

Designer-RSI已验证在1,406个真实用户简报上，五轮迭代即可将执行成功率从72.7%提升至99.3%，且组合拓宽与加深机制显著优于单独使用（58.5% vs 49.4%/48.6%胜率）。技术路径清晰，工具链可基于现有智能体框架搭建。

## 实际使用场景

- 专业图形设计软件智能体操作
- 长时程复杂软件自动化
- 无程序化评判标准的创意任务
- 企业级设计流程辅助

## Demo

用户简报输入 → 冻结前沿模型通过工具调用操作设计软件 → 执行轨迹自动评分 → 匹配重放门控筛选有效变更 → 拓宽：为未覆盖子任务生成新技能 → 加深：根据成功/失败修订现有技能 → 更新程序性记忆库 → 下一轮任务检索技能库辅助执行

## AI 在里面真正做什么？

冻结的前沿模型负责工具调用与执行；外部程序性记忆库存储自然语言技能；匹配重放门控负责质量把关；自动评分器提供噪声反馈信号。

## 技术方案

前沿LLM（如Claude-Sonnet-4/Opus-4.6）、230+设计软件工具API、自然语言技能库（向量数据库+结构化存储）、自动评分器（GenEval2）、匹配重放门控模块、TRL/OpenEnv等训练与评估工具链。

## MVP / 今日目标

今天只完成：选择一款设计软件（如Figma或Photoshop）的50个核心工具，构建初始技能库（20-30个文档衍生技能），在100个真实用户简报上运行3轮迭代，验证执行成功率提升与技能库增长。

- 难度：高。需要集成大量软件工具API、设计可靠的自动评分器、实现匹配重放门控逻辑，并处理噪声反馈下的技能修订稳定性。
- 预计时间：3-6个月
- 预计代码量：约5,000-10,000行（含工具适配层、记忆库管理、评分与门控模块）

## V2

扩展至多软件生态（跨Adobe、Figma、Sketch），引入技能组合与抽象层次，支持多智能体协作共享程序性记忆，并加入人类反馈的轻量校准。
