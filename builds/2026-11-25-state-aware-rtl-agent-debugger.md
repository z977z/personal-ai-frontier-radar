# AI Build of the Day

Date: 2026-11-25

中文名：状态感知RTL智能体调试器  
英文名：State-Aware RTL Agent Debugger  
一句话：让编码智能体看见硬件内部状态，而不只是输出

## 为什么今天做？

AIChipBench证明状态级反馈显著提升接受率并减半工时，而现有智能体工具链普遍只提供输出级测试信号。

## 实际使用场景

- LLM编码智能体自动生成量化解码器RTL
- RTL设计回归与留出序列验证
- 智能体调试反馈接口评测
- 芯片设计自动化教学与竞赛

## Demo

智能体生成RTL→仿真器对照整数参考模型逐周期比对输出与存储状态→定位首个状态不匹配周期→生成状态级反馈（信号名、周期、期望值/实际值）→智能体修正→冻结设计后在留出序列、复位、内存停顿与综合上评分

## AI 在里面真正做什么？

LLM智能体负责RTL编写与修正；系统负责状态级差分、反馈生成与多条件评分

## 技术方案

Verilog/SystemVerilog仿真器（如Verilator）、Python整数参考模型、差分状态追踪、综合工具接口、智能体harness

## MVP / 今日目标

今天只完成：支持单一量化解码器任务，逐周期比对输出与关键状态寄存器，输出首个不匹配周期报告，接入一个编码智能体完成调试闭环

- 难度：高
- 预计时间：6-10周
- 预计代码量：约5000-10000行

## V2

扩展多模型族与第二赛道加速任务，加入综合面积约束、复位与内存停顿注入、留出序列自动生成与排行榜
