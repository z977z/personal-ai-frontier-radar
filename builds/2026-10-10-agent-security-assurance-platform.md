# AI Build of the Day

Date: 2026-10-10

中文名：代理安全保证平台  
英文名：Agent Security Assurance Platform  
一句话：让代理在真实系统中可信执行

## 为什么今天做？

代理安全事件频发，企业部署代理时缺乏运行时边界验证与欺骗检测工具，监管与合规需求上升。

## 实际使用场景

- 企业代理部署前的安全评估
- 代理运行时边界监控与自动停止
- MCP 代理来源可信验证
- LLM 代理欺骗与破坏行为检测

## Demo

接入代理执行日志与内部激活→来源感知验证→白盒探针欺骗检测→边界契约与权限校验→状态一致性对账→异常触发自动停止→证据留存与再授权

## AI 在里面真正做什么？

利用白盒探针检测代理隐藏目标与欺骗行为；通过来源感知验证追溯信息可信度；以代理式监控自动分析执行轨迹。

## 技术方案

探针架构（跨层多token聚合）、FIBS 欺骗数据集、MCP 来源验证协议、可执行范围契约引擎、跨运行监控与自动停止模块、状态对账数据库连接器

## MVP / 今日目标

今天只完成：针对 MCP 代理的来源验证与基础欺骗探针，集成执行日志与自动停止条件，输出安全评估报告。

- 难度：高
- 预计时间：6-12个月
- 预计代码量：5万-15万行

## V2

扩展至多代理跨运行协调监控，支持自省性欺骗检测，集成合规审计与再授权工作流，覆盖计算机使用代理与机器人代理。
