# AI Build of the Day

Date: 2026-09-30

中文名：元推理控制层  
英文名：Meta-Reasoning Controller  
一句话：为长时程 agent 提供显式控制推理层，突破直接控制的性能平台期。

## 为什么今天做？

长时程 agent 任务增多，直接控制策略在预算增加时性能饱和，而 meta-reasoning 在测试预算范围内持续改进。

## 实际使用场景

- 长时程编程 agent
- 复杂研究任务自动化
- 多步骤推理与证明生成
- 需要预算感知的自主系统

## Demo

Worker 执行任务级计算 -> Controller 整合运行状态 -> 探索下一步选项 -> 评估剩余预算下各选项价值 -> 从持久记忆派发选定工作 -> 循环直至完成或预算耗尽。

## AI 在里面真正做什么？

Controller 使用 LLM 进行结构化推理，评估选项和预算；Worker 使用 LLM 执行具体任务计算。

## 技术方案

LLM API（如 GPT-5.5、Opus 4.8）、持久记忆存储、任务执行环境、预算管理器。

## MVP / 今日目标

今天只完成：实现一个最小 Controller-Worker 循环，支持状态整合、选项探索和预算评估，在单一长时程任务上对比直接控制。

- 难度：中高
- 预计时间：2-4 周
- 预计代码量：2000-5000 行

## V2

引入自适应控制粒度、多 Controller 协作、跨任务记忆迁移和 artifact-graph 分析工具。
