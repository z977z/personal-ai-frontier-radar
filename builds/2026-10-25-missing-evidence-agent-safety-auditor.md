# AI Build of the Day

Date: 2026-10-25

中文名：缺失证据智能体安全审计器  
英文名：Missing-Evidence Agent Safety Auditor  
一句话：在信息不全时，先问再动。

## 为什么今天做？

工具调用智能体进入生产环境，而现有安全评测多假设信息完整；EpiSEM-Bench 提供了可复用的任务构造与审计思路，使构建轻量审计工具具备可行性。

## 实际使用场景

- 企业智能体上线前的安全红队测试
- 工具调用智能体的持续安全监控
- 智能体训练中的证据恢复能力评估
- 高风险领域（金融、医疗、运维）的智能体合规审计

## Demo

构造任务对（安全/不安全）→ 系统性抑制关键事实 → 运行被测智能体 → 记录是否执行禁止动作 → 审计是否主动查询缺失事实 → 输出遗漏鲁棒性、证据获取率、适当行动率三项指标

## AI 在里面真正做什么？

被测智能体为工具调用型 LLM；审计器本身可用规则加小模型判断动作是否越界，并检测是否发起澄清查询。

## 技术方案

Python + 任务定义 DSL（YAML/JSON）+ 工具模拟环境 + LLM 调用接口 + 指标看板

## MVP / 今日目标

今天只完成：选取 2 个领域、各 30 对匹配任务，实现事实抑制、动作越界判定和澄清查询检测，输出三项指标报告。

- 难度：中
- 预计时间：2-4 周
- 预计代码量：约 3000-5000 行

## V2

扩展至六领域 300 对任务，加入最小失败基数搜索、多模型对比和 CI 集成，支持自定义工具环境接入。
