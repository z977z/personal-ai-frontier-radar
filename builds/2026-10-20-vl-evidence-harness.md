# AI Build of the Day

Date: 2026-10-20

中文名：多模态证据工具框架  
英文名：VL Evidence Harness  
一句话：让视觉智能体调用工具、留存证据、用代码组合答案

## 为什么今天做？

OpenVLHarness 证明工具+持久记忆+代码执行可在多骨干上稳定提升9.7-12.6分，且token成本更低，架构可复用。

## 实际使用场景

- 图表与文档视觉问答
- 需要外部检索与数值测量的研究型问答
- 多步骤视觉证据核验与报告生成

## Demo

用户查询→规划器选择工具→能力层调用异构后端→证据渲染为模型可读观察→写入持久多模态记忆（图像/结构化数据/网页引用）→代码接口在存储数据上执行组合计算→迭代直至生成带引用答案

## AI 在里面真正做什么？

MLLM作为规划器与证据解释器，决定工具调用序列、检查渲染证据、生成组合程序并综合结论

## 技术方案

Python + 多模态LLM API + 工具适配层 + 向量/对象存储记忆 + 沙箱代码执行 + 证据渲染器

## MVP / 今日目标

今天只完成：实现3-5个工具（网页检索、OCR、图表解析、计算器）、记忆存储与代码执行沙箱，在单一视觉问答基准上对比无工具基线

- 难度：中高
- 预计时间：4-8周
- 预计代码量：约5k-15k行

## V2

加入工具自动发现与路由、记忆压缩与检索、多智能体分工、成本感知的推理预算调度
