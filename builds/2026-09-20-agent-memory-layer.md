# AI Build of the Day

Date: 2026-09-20

中文名：智能体记忆层  
英文名：Agent Memory Layer  
一句话：为你的 AI 智能体赋予持久、可检索的记忆

## 为什么今天做？

大模型上下文有限，且智能体需要跨会话保持一致性。现有向量数据库和检索技术成熟，可构建轻量级记忆层。

## 实际使用场景

- 编码助手记住项目结构和用户偏好
- 客服机器人保留历史对话
- 个人助理跟踪长期任务

## Demo

智能体交互 -> 提取关键信息 -> 嵌入并存储 -> 检索相关记忆 -> 注入提示

## AI 在里面真正做什么？

使用 LLM 进行信息提取、摘要和相关性判断；嵌入模型用于检索。

## 技术方案

Python, LangChain/LlamaIndex, 向量数据库 (Chroma/Weaviate), OpenAI/本地嵌入模型

## MVP / 今日目标

今天只完成：实现一个简单的记忆存储和检索模块，支持添加、查询和删除记忆，并集成到 LangChain 智能体。

- 难度：中等
- 预计时间：2-3 周
- 预计代码量：约 1000-2000 行

## V2

增加记忆重要性评分、遗忘机制、多模态记忆和分布式存储。
