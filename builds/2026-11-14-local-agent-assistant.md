# AI Build of the Day

Date: 2026-11-14

中文名：本地智能体助理  
英文名：Local Agent Assistant  
一句话：在设备上运行的小参数智能体，离线完成规划、工具调用与语音交互。

## 为什么今天做？

亚十亿参数智能体模型与高质量端侧 TTS 同时可用，使隐私优先的本地助理具备可行性。

## 实际使用场景

- 离线个人日程与提醒管理
- 隐私敏感文档的本地检索与摘要
- 无网络环境下的语音指令执行

## Demo

语音输入→端侧 TTS/ASR→亚十亿参数智能体规划→本地工具调用（日历、文件、检索）→结果合成与语音播报

## AI 在里面真正做什么？

智能体模型负责意图理解、任务分解与工具选择；TTS 负责自然语音输出。

## 技术方案

亚十亿参数智能体模型（如 BotPsy 路线）、端侧 TTS（如 Phonon TTS）、本地向量检索、设备端工具 API

## MVP / 今日目标

今天只完成：实现语音指令到本地日历/文件操作的闭环，全部推理在设备完成。

- 难度：中高
- 预计时间：4-8 周
- 预计代码量：约 3k-8k 行（含工具适配与端侧推理集成）

## V2

加入本地记忆与多步任务规划，扩展工具集并引入端侧检索增强。
