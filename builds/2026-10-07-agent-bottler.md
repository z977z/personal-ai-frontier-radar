# AI Build of the Day

Date: 2026-10-07

中文名：代理瓶颈优化器  
英文名：Agent Bottler  
一句话：将昂贵的一次性代理调用转化为低成本可复用工件

## 为什么今天做？

LLM API 成本高企，而企业存在大量重复性任务（如分类、抽取）。代理可自主分析工作负载，选择蒸馏小模型或合成程序，实现成本数量级下降。

## 实际使用场景

- 大规模查询-产品相关性分类
- 客户反馈批量分类
- 文档信息抽取
- 重复性数据清洗

## Demo

1. 代理接收未标注工作负载和预算约束；2. 分析任务类型和重复模式；3. 选择策略：训练小模型、编写规则程序或合成数据；4. 在预算内执行并评估质量；5. 输出可复用工件（模型或程序）及成本报告。

## AI 在里面真正做什么？

代理作为元优化器，自主决策资源分配、策略选择和工件生成，并评估质量-成本权衡。

## 技术方案

Python, PyTorch, Hugging Face Transformers, 代理框架（如 LangChain）, 成本追踪工具

## MVP / 今日目标

今天只完成：针对文本分类任务，代理自动决定是否训练小型 DistilBERT 或生成正则表达式，在给定预算内最大化 F1。

- 难度：高
- 预计时间：3-6个月
- 预计代码量：5k-10k行

## V2

支持多模态任务和更复杂的程序合成，集成主动学习以优化数据标注，并引入人类反馈校准成本-质量权衡。
