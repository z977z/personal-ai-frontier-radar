# AI Build of the Day

Date: 2026-08-31

中文名：来源核验助手  
英文名：Source Grounding Checker  
一句话：检查 AI 摘要里的事实是否有来源支撑。

## 为什么今天做？

与今日情报系统的来源验证需求直接相关。

## 实际使用场景

- 日报事实核查
- 研究笔记审阅
- 产品发布摘要检查

## Demo

User → 粘贴摘要与来源 → AI 提取主张 → 程序匹配证据 → 核验结果

## AI 在里面真正做什么？

AI 提取可核验主张并解释证据缺口；URL 与匹配结果由程序保存。

## 技术方案

Python CLI + JSON + 当前 LLM Provider

## MVP / 今日目标

今天只完成：输入一段摘要和来源列表，输出 supported/unconfirmed 主张。
