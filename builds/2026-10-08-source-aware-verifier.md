# AI Build of the Day

Date: 2026-10-08

中文名：来源感知验证器  
英文名：Source-Aware Verifier  
一句话：为 MCP 智能体提供可信来源验证

## 为什么今天做？

MCP 智能体正快速普及，但来源可靠性问题突出，亟需工具来验证智能体所引用信息的来源可信度。

## 实际使用场景

- 企业智能体合规审计
- 科研智能体数据溯源
- 金融智能体信息验证
- 医疗智能体知识来源核查

## Demo

智能体调用外部工具 -> 捕获来源元数据（URL、作者、时间等）-> 来源可信度评分（基于权威性、时效性、一致性）-> 与事实验证结合 -> 输出验证报告或拦截不可信来源。

## AI 在里面真正做什么？

使用轻量级模型对来源进行可信度分类和评分，结合规则引擎和知识库进行交叉验证。

## 技术方案

Python, FastAPI, LangChain, MCP SDK, 可信来源数据库, 轻量级分类模型（如 DistilBERT）

## MVP / 今日目标

今天只完成：实现一个中间件，拦截 MCP 工具调用，记录来源并调用可信度评分 API，对低可信度来源发出警告。

- 难度：中等
- 预计时间：2-3 个月
- 预计代码量：约 5000 行

## V2

增加动态来源信誉学习、跨智能体来源共享、实时来源监控和自动修复建议。
