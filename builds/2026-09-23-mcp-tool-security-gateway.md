# AI Build of the Day

Date: 2026-09-23

中文名：MCP工具安全网关  
英文名：MCP Tool Security Gateway  
一句话：为MCP智能体提供工具元数据审核与运行时隔离的安全中间层

## 为什么今天做？

A2M攻击表明MCP生态存在严重的语义供应链风险，恶意工具可通过元数据和输出劫持智能体。当前MCP部署缺乏对第三方工具的验证与隔离，安全网关可立即填补这一空白。

## 实际使用场景

- 企业级MCP智能体平台
- 第三方工具市场审核
- 高风险领域（金融、医疗）智能体部署
- 多智能体协作环境

## Demo

智能体发起工具调用请求 → 网关拦截并检查工具元数据签名与信誉 → 对工具返回内容进行异常检测与净化 → 在隔离沙箱中执行工具调用 → 记录执行轨迹用于审计与攻击溯源 → 动态更新工具风险评分

## AI 在里面真正做什么？

使用轻量级分类模型检测工具元数据中的诱导性语义和返回内容中的对抗性模式；利用执行轨迹训练异常检测模型；通过持续学习适应新型攻击。

## 技术方案

Python/FastAPI网关；MCP协议解析库；工具元数据签名验证（如Sigstore）；沙箱运行时（gVisor/Firecracker）；异常检测模型（小型Transformer或GBDT）；审计日志（Elasticsearch）；风险评分数据库（Redis）。

## MVP / 今日目标

今天只完成：实现MCP代理网关，支持工具元数据签名验证、返回内容关键词过滤和调用频率限制；提供基础审计日志和告警。

- 难度：中高。需深入理解MCP协议、智能体决策机制和攻击面，同时保证低延迟不干扰正常调用。
- 预计时间：6-8周
- 预计代码量：约8000-12000行
