# AI Build of the Day

Date: 2026-10-21

中文名：日志语义图根因诊断器  
英文名：LogGraph RCA Agent  
一句话：把杂乱日志变成可查询的因果图，让智能体自动定位故障根因

## 为什么今天做？

日志量爆炸与LLM上下文成本矛盾突出，先图结构化再推理可同时降噪与降token

## 实际使用场景

- 微服务级联故障排障
- SRE值班辅助
- 发布后异常影响面评估

## Demo

日志采集与解析→实体与关系抽取构建属性图→异常检测触发→多智能体在图上做因果剪枝与时间回溯→LLM生成根因与修复建议

## AI 在里面真正做什么？

LLM负责日志语义抽取、图查询规划与根因解释生成，因果算法负责剪枝定位

## 技术方案

Python、Neo4j或NetworkX、日志解析器（Drain等）、LangGraph类编排、LLM API

## MVP / 今日目标

今天只完成：单服务拓扑的日志入图、异常节点定位与LLM根因报告生成

- 难度：中高
- 预计时间：4-8周
- 预计代码量：约5000-10000行

## V2

接入多集群拓扑、因果图算法优化、幻觉校验与MTTR量化评估
