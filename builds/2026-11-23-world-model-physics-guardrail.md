# AI Build of the Day

Date: 2026-11-23

中文名：世界模型物理安全护栏  
英文名：World Model Physics Guardrail  
一句话：给视频世界模型加一层轻量穿透检测与安全动作替换，让仿真规划不再穿墙。

## 为什么今天做？

NoPeWorld证明冻结DiT隐藏状态即可读出穿透风险，且零样本泛化到新视角与移动障碍，改造成本远低于重训练世界模型，适合作为即插即用安全层。

## 实际使用场景

- 具身智能仿真中的导航与操作规划
- 游戏/VR内容生成的物理合理性校验
- 机器人策略在世界模型中的预演安全过滤
- 视频生成产品的穿模后处理

## Demo

输入候选动作与当前观测 → 世界模型DiT前向得到隐藏状态 → 轻量预测头输出穿透风险分 → 若不安全则在候选动作集中搜索最保留原意图的安全替代 → 执行安全动作并继续生成

## AI 在里面真正做什么？

DiT隐藏状态作为物理风险特征提取器；小型预测头做二分类安全判定；动作替换模块在意图保持约束下做安全动作选择。

## 技术方案

PyTorch + 预训练视频世界模型（DiT类）+ 轻量MLP/线性预测头 + NoPeBench评测基准 + 动作候选搜索

## MVP / 今日目标

今天只完成：在单一开源视频世界模型上复现NoPeWorld：采集NoPeBench子集，训练隐藏状态探针，实现不安全动作替换，报告违规率下降幅度。

- 难度：中
- 预计时间：2-4周
- 预计代码量：约2k-5k行（含评测与训练脚本）

## V2

扩展到多物体接触与可变形体约束；引入在线自适应预测头；与VLA策略联合训练形成闭环安全规划。
