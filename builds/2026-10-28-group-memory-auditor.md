# AI Build of the Day

Date: 2026-10-28

中文名：群体决策记忆审计器  
英文名：Group Memory Auditor  
一句话：在压缩前审计证据平衡，剥离归属偏置，提升LLM群体决策准确率。

## 为什么今天做？

CrossProfile基准已给出可复现的失效模式与量化提升（移除归属标签提升13至24分），可立即转化为工程检查项。

## 实际使用场景

- 多智能体辩论系统
- 会议纪要压缩与决策支持
- AI评审团聚合
- 企业知识库问答的群体推理

## Demo

输入讨论转录→抽取事实主张及其归属标签→计算支持/诱饵/无关事实的证据平衡→标记相关性过滤风险→生成去归属的平衡记忆→输出给决策模型并记录审计日志

## AI 在里面真正做什么？

用LLM抽取事实与归属、判定事实与决策标准的相关性，并用规则或小模型校验证据平衡；决策模型仅接收去归属记忆。

## 技术方案

Python、任意LLM API（Qwen/Llama/DeepSeek）、CrossProfile式模板生成器、轻量规则引擎、可选向量检索

## MVP / 今日目标

今天只完成：实现事实抽取与归属剥离、证据平衡统计、相关性诱饵告警三项功能，在自建小规模隐藏剖面任务上对比有无审计的准确率。

- 难度：中
- 预计时间：2至3周
- 预计代码量：约1500至2500行

## V2

加入自动生成对抗性隐藏剖面任务、多轮记忆更新、与辩论框架集成、在线A/B评估归属偏置消除效果。
