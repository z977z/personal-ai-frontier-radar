# AI Build of the Day

Date: 2026-10-27

中文名：实时代码安全门禁探针  
英文名：Realtime Code Safety Probe  
一句话：在代码生成的下一秒给出漏洞判定，而不是几分钟后

## 为什么今天做？

REVA证明单次前向+探针可在约1秒内达到智能体级检测准确率，且成本极低；编码智能体普及使实时拦截成为刚需。

## 实际使用场景

- IDE/编码智能体生成函数时即时漏洞告警
- CI流水线中作为低成本预筛，减少昂贵智能体审计调用
- 代码评审助手按风险排序待审函数

## Demo

新函数提交→构建模块级威胁模型与调用图→运行轻量静态分析→拼接上下文提示→LLM单次前向→探针读取内部表示→输出风险分与判定→高风险转交智能体深度审计

## AI 在里面真正做什么？

LLM提供上下文感知的代码理解表示，探针将内部表示映射为校准的风险判定；智能体仅处理被升级的高风险样本。

## 技术方案

开源LLM（如GLM系列）+静态分析工具（Semgrep/CodeQL轻量规则）+调用图构建+线性探针训练（标注漏洞数据集如PrimeVul）+推理服务

## MVP / 今日目标

今天只完成：针对单一语言（Python/JS）与单一漏洞类型（注入类），在PrimeVul子集上训练探针，接入pre-commit钩子，输出风险分与解释片段。

- 难度：中高：需漏洞标注数据、探针校准与低误报调优，上下文构建工程量大。
- 预计时间：6–10周
- 预计代码量：约5k–10k行（含数据管道、探针训练、服务与插件）

## V2

扩展多语言与多漏洞类型；加入主动上下文补全（按需检索调用方）；在线学习适配项目私有代码风格；与智能体审计形成级联。
