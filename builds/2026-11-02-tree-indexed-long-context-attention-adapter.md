# AI Build of the Day

Date: 2026-11-02

中文名：树索引长上下文注意力适配器  
英文名：Tree-Indexed Long-Context Attention Adapter  
一句话：用分层 KV 摘要树把现有模型的上下文窗口低成本扩展到百万级

## 为什么今天做？

ZHA 证明分层树状索引器可实现端到端次二次注意力，且仅需数亿 token 的 KL 蒸馏即可适配预训练模型，工程路径清晰。

## 实际使用场景

- 超长文档与代码库检索问答
- 长程 agent 的持久上下文
- 多轮超长对话记忆
- 大规模日志/审计分析

## Demo

输入长序列 → 构建 KV cache 递归压缩摘要树 → 查询自顶向下路由至稀疏 key 子集 → 对选中 key 做精确注意力 → 输出；训练阶段用原模型注意力分布做 KL 蒸馏。

## AI 在里面真正做什么？

编码模型/LLM 负责生成摘要树节点与路由决策；蒸馏阶段原模型作为教师提供注意力分布监督。

## 技术方案

PyTorch + FlashAttention 内核 + KV cache 管理 + KL 蒸馏训练脚本 + 长上下文评测（检索/推理/代码）

## MVP / 今日目标

今天只完成：在 128K 上下文开源模型上实现 2-3 层树索引器，完成短蒸馏并在长上下文检索基准上对齐原模型 95% 以上性能。

- 难度：高
- 预计时间：6-10 周
- 预计代码量：约 3000-6000 行（含内核与训练脚本）

## V2

支持 6 层深树与动态深度增长、多查询批处理优化、与推理框架（vLLM 类）集成，并扩展到多模态 KV 摘要。
