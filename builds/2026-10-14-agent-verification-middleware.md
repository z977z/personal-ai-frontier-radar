# AI Build of the Day

Date: 2026-10-14

中文名：智能体验证中间件  
英文名：Agent Verification Middleware  
一句话：为智能体行动提供实时可信验证层

## 为什么今天做？

智能体正从实验走向生产，但错误行动成本高昂。现有框架缺乏系统化的验证组件，而近期研究提供了可落地的技术（如 DeRef、源感知验证）。

## 实际使用场景

- 企业流程自动化中的工具调用验证
- 个人助手执行敏感操作（如支付、预约）前的确认
- 多智能体协作中的行动一致性检查
- 合规审计场景下的操作溯源

## Demo

智能体生成行动提案 → 验证中间件拦截 → 提取行动参数和上下文 → 来源追踪与参考生成 → 多维度验证（参数正确性、来源可信度、状态一致性） → 返回验证结果（通过/拒绝/需人工确认） → 智能体执行或调整

## AI 在里面真正做什么？

使用轻量级 LLM 或专用模型进行参考生成（如 DeRef）、来源可信度分类、参数合理性判断；同时可结合规则引擎进行确定性检查。

## 技术方案

Python/TypeScript，集成 LangChain/AutoGen 等智能体框架，使用 ONNX 或 vLLM 部署验证模型，向量数据库存储来源证据，规则引擎（如 Drools）处理硬性约束。

## MVP / 今日目标

今天只完成：实现工具调用参数验证模块，支持从对话历史中提取参考值，对默认值、推断值进行验证，输出通过/拒绝信号。

- 难度：中等
- 预计时间：2-3个月
- 预计代码量：5k-10k行

## V2

增加多智能体交叉验证、实时数据库状态比对、自适应验证策略（根据风险等级调整严格度）、可视化审计日志。
