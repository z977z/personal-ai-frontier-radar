## 2. RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

AI Importance Score：5.7 / 10

**Facts：** 论文提出 RATED（Reliability-Aware Tool Retrieval via Execution Dynamics），一种结合语义匹配与动态可靠性适应的工具检索框架。采用冻结双编码器对比微调进行语义匹配，并引入轻量上下文赌博机模块根据实时执行反馈重排候选工具。发布 EcoAgent 基准，包含 5,172 个真实工具和超过 210,000 个查询-工具对。实验显示，在真实查询上 MRR 相对 ToolLLM API 检索器提升 52.2%，在 30% 失败率的严重 API 中断场景下将故障选择率从 86.2% 降至 2.9%，延迟开销小于 1ms。代码与数据集已开源。

**Analysis：** 该工作针对 AI 代理工具检索中忽视运行时可用性的问题，将语义匹配与在线可靠性学习结合，方法设计合理且实验充分。上下文赌博机模块使系统能快速适应工具故障而无需重训练，具有较强工程实用性。开源基准 EcoAgent 有助于推动该方向研究。

**技术看点：** 提出可靠性感知的工具检索框架，融合对比学习与上下文赌博机，实现动态故障适应；构建大规模真实工具基准。

**可能影响：** 可显著提升 AI 代理在工具调用中的鲁棒性，降低因工具故障导致的错误，对代理系统落地有直接推动作用。

## Emerging AI Concept

中文名称：代理工具可靠性感知检索  
英文名称：Reliability-Aware Tool Retrieval for Agents  
Emerging Score：7.5  
成熟度：Emerging

### 一句话理解

该概念指 AI 代理在调用外部工具时，不仅基于语义相关性检索工具，还动态考虑工具的实时可用性和可靠性，以避免因工具故障导致任务失败。RATED 是该方向的代表性工作，通过上下文赌博机实现运行时适应。

### 为什么现在值得关注？

随着 AI 代理越来越多地依赖外部工具，工具故障成为影响代理可靠性的关键因素。传统语义检索忽视运行时状态，亟需可靠性感知的检索机制。
