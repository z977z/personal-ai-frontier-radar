## 🔥 Today's Big Story

**CordisBench: Can Language Models Reason About Component Lifecycles in Dynamic Agent Harnesses?**

CordisBench is a benchmark with 1,200 questions designed to test language models' reasoning about component lifecycles in dynamic agent harnesses. It uses a formal setting with programs executed against Cordis, a runtime managing component dependencies and cleanup. Tasks include identifying affected components, predicting state after teardown orders, determining conditions under all/some orders, and choosing successful reconfigurations. Evaluated three efficiency-oriented models at low reasoning effort with varying interactions (2-32). Models handle small systems well but degrade with more interactions, especially in predicting final state and reasoning across teardown orders. Additional inference effort helps some models. On a 16-interaction subset, GPT-5.6 Luna uses nearly 3,000 reasoning tokens per question at medium effort. An independent finite reference semantics agrees with Cordis execution on all 528 executable questions.

**分析：** The benchmark highlights a scalability issue in lifecycle reasoning for agent harnesses. The cost of reasoning tokens is significant, suggesting inefficiency. The agreement with finite reference semantics indicates potential for more efficient symbolic reasoning instead of LLM token-heavy inference.

## 3. Selective Agent Guidance via Entropy: Learning Autonomous Policies from Imperfect VLM Teachers

AI Importance Score：5.9 / 10

**Facts：** SAGE (Selective Agent Guidance via Entropy) is a framework that learns a lightweight RL policy from an imperfect VLM teacher. It queries the VLM only when the learner is uncertain, executes suggested actions during training, and distills guidance into the policy. It weights teacher-action distillation using environment-derived advantages. Evaluated on sparse-reward visual reasoning and navigation tasks, SAGE learns policies that act without VLM guidance at evaluation, improving over unguided RL in several environments, sometimes exceeding the teacher. It reduces VLM usage and requires no VLM calls at deployment.

**Analysis：** SAGE demonstrates that VLMs can be used as temporary guides rather than fixed policies, making them more practical for deployment. The selective querying based on uncertainty and advantage weighting addresses the brittleness and cost of using VLMs directly.

**技术看点：** Offers a method to distill knowledge from large VLMs into efficient RL policies, reducing computational cost and improving robustness.

**可能影响：** Could enable more practical use of VLMs in interactive decision-making, especially in resource-constrained settings.

**Sources：**

- [arXiv AI](https://arxiv.org/abs/2609.01567v1)

## Emerging AI Concept

中文名称：智能体生命周期推理  
英文名称：Agent Lifecycle Reasoning  
Emerging Score：6.0  
成熟度：Emerging

### 一句话理解

智能体生命周期推理是指语言模型在动态智能体框架中理解和推理组件生命周期（如依赖、清理、配置变化）的能力。随着智能体系统越来越复杂，这种推理能力对于确保系统的正确性和可靠性至关重要。

### 为什么现在值得关注？

随着动态智能体框架的兴起，语言模型被赋予改变自身执行环境的能力，这带来了新的推理挑战。CordisBench等基准的出现表明该领域正在成为研究热点。
