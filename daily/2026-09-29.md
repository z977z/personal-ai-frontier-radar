## 2. TokenCast: Forecasting Token Consumption During LLM Agent Execution

AI Importance Score：7.5 / 10

**Facts：** TokenCast 提出预测 LLM 智能体执行期间 token 消耗的方法。同一任务多次运行 token 消耗可能相差一个数量级。TokenCast 为每个执行段学习可组合的成本表示，记录自身消耗和引入的上下文增长。组合相邻段得到累积估计，捕捉早期段上下文被后续调用重新读取的额外输入成本。随着执行展开，新观察到的证据刷新预测，无需额外 LLM 调用，在 SWE-bench Verified 上平均累积预测时间为每次运行 32.8 毫秒。在 4 个任务套件和 6 个智能体模型上，TokenCast 相对于最强比较器的平均绝对误差降低平均为 14.5%（96 个评估组合）。在离线预算控制重放中，TokenCast 在匹配轨迹完成时比固定预算策略平均少用 21.3% 的 token。代码已在 GitHub 开源。

**Analysis：** TokenCast 解决了 LLM 智能体执行中 token 消耗难以预测的问题，这对于成本控制和资源分配至关重要。其创新点在于将执行分解为段，学习可组合的成本表示，并动态更新预测，无需额外 LLM 调用，效率高。实验表明在多个任务和模型上显著降低预测误差，并在预算控制中节省 token。

**技术看点：** 高。提供了一种高效、准确的 token 消耗预测方法，可集成到智能体框架中，优化资源使用。

**可能影响：** 对 LLM 智能体的成本管理和部署有直接帮助，可降低运营成本，提高预算控制能力。

**Sources：**

- [arXiv AI](https://arxiv.org/abs/2609.35760v1)

Emerging Score：8.0  
成熟度：Emerging

### 一句话理解

智能体评估与优化涵盖对 AI 智能体性能、可靠性、成本效率的评估和改进方法。包括自动评分标准生成、一致性评估、token 消耗预测等。随着智能体在复杂任务中的应用增多，如何可靠地评估和优化其行为成为关键挑战。

### 为什么现在值得关注？

LLM 智能体正从研究走向实际部署，但在金融、软件工程等领域的评估仍依赖昂贵的人工专家，且执行成本难以预测。近期研究如 FinAutoRubric 和 TokenCast 提供了自动化评估和成本预测的解决方案，推动了该领域的发展。
