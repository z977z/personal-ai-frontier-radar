## 3. NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities

**Facts：** 论文提出NemotronLabs VoiceChat，一个开放的全双工语音到语音模型，具备原生工具调用能力。模型结合流式语音编码器、仅解码器语言模型、并行专用输出流（智能体文本和结构化函数调用）、辅助RNN-T分支用于增量用户转录，以及流式TTS解码器。在Full-Duplex-Bench 1.0上，在评估的开放权重系统中取得最低暂停处理接管率，用户打断后100%接管，打断后响应质量4.33/5。在Full-Duplex-Bench 1.5上，93%情况下在用户反馈后恢复响应。VoiceBench归一化平均55.1，Full-Duplex-Bench 3.0工具选择F1为82.5%，但参数准确性和端到端工具执行仍有改进空间。

## Emerging AI Concept

中文名称：智能体程序性记忆  
英文名称：Agentic Procedural Memory  
Emerging Score：8.5  
成熟度：Emerging

### 一句话理解

智能体程序性记忆指智能体将成功与失败经验转化为可复用的自然语言技能或程序，存储于外部记忆库中，并在后续任务中检索、组合与精炼。与参数化记忆不同，它不更新模型权重，而是通过记忆的拓宽（获取新技能）和加深（修订现有技能）实现持续适应。Designer-RSI展示了该概念在专业设计软件中的有效性，技能库从76增长到139，执行成功率从72.7%提升至99.3%。

### 为什么现在值得关注？

当前前沿模型能力强大但权重冻结，无法通过梯度更新适应新任务；同时智能体在长时程、无程序化评判标准的任务中需要积累经验。程序性记忆提供了一条无需权重更新、无需人工标签的持续适应路径，且自然语言技能表示便于审计与迁移。

## 🛠 AI Build of the Day

**设计智能体程序性记忆库 / Design Agent Procedural Memory Bank**

- MVP：选择一款设计软件（如Figma或Photoshop）的50个核心工具，构建初始技能库（20-30个文档衍生技能），在100个真实用户简报上运行3轮迭代，验证执行成功率提升与技能库增长。
- 难度：高。需要集成大量软件工具API、设计可靠的自动评分器、实现匹配重放门控逻辑，并处理噪声反馈下的技能修订稳定性。
