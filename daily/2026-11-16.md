**WeightBench: Evaluating Language Models as Weight-Space Programmers**

arXiv 论文提出 WEIGHTBENCH 基准，评估 LLM 作为“权重空间程序员”（WSP）的能力，覆盖 42 个任务、五个赛道：读取权重、修复权重、编写权重、识别不可能编辑、无数据压缩；网络规模从 2K 参数控制策略到 7B 语言模型。结果显示前沿智能体已能读取小网络并在不运行的情况下写出可工作的控制策略，但尚不能修补语言模型、无数据压缩或区分“不可能编辑”与“困难编辑”。Claude Opus 5.5 宏平均 0.535，Sonnet 5.5 为 0.466，Haiku 5.5 为 0.402，DeepSeek v4-flash 为 0.215；GPT-6.1-sol 在 38 个任务上达 0.568，Opus 为 0.546。代码与排行榜公开于 GitHub。

**分析：** 该工作把“LLM 直接操作神经网络参数”从零散演示提升为系统化基准，并给出明确的能力边界：小网络可读可写，大模型修补与无数据压缩仍是瓶颈。分数普遍偏低说明 WSP 尚处早期，但赛道设计（含“不可能编辑”识别）对评估模型自我认知有方法论价值。

## 4. ModHarness-RL: Recasting Harnesses as Learnable and Evolving Programs for Agentic RL

AI Importance Score：7 / 10

**Facts：** arXiv 论文提出 ModHarness-RL，将智能体 RL 中的 harness（模型交互脚手架）重构为可从数据学习并随模型训练演化的程序。方法将交互记录为结构化 State（类型化块），harness 的两个核心组件——Compression 程序（组装历史为上下文）与 Steering 程序（行为偏离时提供引导）——均为 State 上的程序；训练中从近期轨迹提出候选程序，经执行验证并在历史轨迹上重放。在 CodeSearch 深入研究，并分析 ALFWorld 与 BIRD SQL，模型规模 1.5B 至 8B；多数设置下优于固定 harness 基线。

**Analysis：** 该工作把“提示工程/脚手架”从手工设计转为可学习、可演化的程序，与模型共同训练，思路新颖。Compression 与 Steering 的分离设计便于模块化复用；但实验集中在中等规模模型与特定任务，泛化到更大模型与开放环境仍需验证。

**技术看点：** 提出 harness 即程序的范式，并给出候选生成—执行验证—历史重放的训练闭环。

**可能影响：** 可能改变智能体 RL 的训练流程，使脚手架随模型能力自适应，降低人工调参成本。

**Sources：**

- [arXiv AI](https://arxiv.org/abs/2611.18533v1)

## 5. Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination

AI Importance Score：7 / 10

**Facts：** arXiv 论文以网页智能体“幻觉出不存在的网页元素”为案例，检验机制可解释性（MI）工具解释 LLM 智能体失败的能力。对 Qwen2.5-7B-Instruct 与真实网站交互分析发现：基于最后提示 token 训练的线性探针可在生成前预测幻觉（AUC 0.80），沿探针方向引导可纠正 85% 的幻觉，但会破坏 7% 的有效动作；探针方向对提示格式敏感，动作表示方式微调后引导效果大幅下降；电路识别困难，计算分散于多组件与位置，依赖信息因例而异。

**Analysis：** 该文诚实揭示了 MI 在真实智能体失败解释上的局限：探针可预测但解释不完整，且脆弱于格式变化。这对“用 MI 做智能体安全监控”的乐观预期是重要修正，也指出需要面向智能体场景改造 MI 方法。

**技术看点：** 提供幻觉预测与引导的定量结果，并系统列出 MI 方法在智能体场景的失效模式。

**可能影响：** 影响智能体可靠性监控与可解释性工具的设计方向，强调鲁棒性优先于单点准确率。

**Sources：**

- [arXiv AI](https://arxiv.org/abs/2611.18514v1)

## Emerging AI Concept

中文名称：权重空间编程  
英文名称：Weight-Space Programming  
Emerging Score：7  
成熟度：Emerging

### 一句话理解

让大语言模型直接读取、修复和编写其他神经网络的参数，无需梯度下降即可完成模型操作，是“模型操作模型”的新范式。

### 为什么现在值得关注？

WEIGHTBENCH 首次系统化评测该能力，显示前沿智能体已能读写小网络，但修补大模型与无数据压缩仍是瓶颈，标志该方向从演示走向可度量研究。
