**Agent-Editing World Model: Rethinking World Modeling for LLM Agents**

## 2. Can LLMs Reason About Runtime Behavior? A Repository-Level Dynamic Benchmark

AI Importance Score：7 / 10

**Facts：** 论文提出 SWE-Flux，一个仓库级动态执行推理基准，含 12 个真实 Python 仓库的 480 个执行接地实例，金标准答案由插桩测试执行自动采集而非人工编写或 LLM 评判。覆盖单测试与多测试问题，涉及控制流、循环、程序状态、数据流、异常和程序不变量。评估五个 LLM，最佳模型仅 37% 准确率；模型在局部行为（不变量、过程内控制流、异常、简单循环）上表现较好，但在数据流、跨过程执行、精确状态推理和套件级聚合上表现差。oracle-harvesting 流水线可通过输入扰动生成新变体，约 90% 选中实例可成功采集有效变体，且变体对模型更具挑战性。

**Analysis：** 该基准填补了仓库级动态执行推理评测的空白，自动采集金标准避免了 LLM 评判偏差，方法学上更可靠。37% 的最佳准确率揭示当前 LLM 在跨过程数据流与状态推理上的显著短板，为后续研究提供明确方向。输入扰动生成变体的机制提升了基准的可扩展性与抗污染能力。局限在于仅覆盖 Python 仓库，语言与生态多样性有限。

**技术看点：** 高。提供可复现、可扩展的仓库级动态推理评测工具，自动采集与变体生成流水线可被其他基准借鉴，对代码 LLM 能力诊断有直接价值。

**可能影响：** 为代码 LLM 的执行推理能力提供更严格评测标准，可能推动模型在跨过程数据流与状态推理方向的改进，并影响仓库级代码 agent 的评估方式。

## 3. When and Where to Trust the Teacher: Unifying On-Policy Distillation and GRPO through Entropy-Calibrated Credit Assignment

AI Importance Score：7 / 10

**Facts：** 论文提出 UECR-GRPO，在单一 GRPO 风格更新中于响应级和 token 级整合 verifier 与 teacher 信号。Path-Utility Unification (PUU) 将 verifier 奖励与 teacher-to-anchor 路径对数比结合在 KL 正则化目标中，on-policy 实现使用长度归一化 teacher 分数，在组归一化和 PPO 裁剪前合并两种奖励。Entropy-Calibrated Redistribution (ECR) 使用带符号的 teacher-old-policy token 差距重分配 verifier 分量，全词表 teacher 熵衰减不确定指导，响应级零和投影保持总任务信用与 token 符号。在五个数学推理基准上，Qwen3-1.7B 和 Qwen3-4B 学生 Avg@12 分别达 17.21% 和 65.09%，各规模超最强基线 0.89 和 0.56 个百分点。

**Analysis：** 该工作针对 RLVR 仅提供最终答案监督、OPD 教师偏好未必反映正确性的问题，提出在组归一化前融合 verifier 与 teacher 信号，并用熵校准重分配 token 信用。方法设计细致，兼顾响应排序与 token 级信用保持。提升幅度较小（<1 个百分点），但方向明确。局限在于仅在数学推理与 Qwen3 系列上验证，跨领域与跨模型泛化待确认。

**技术看点：** 高。PUU 与 ECR 提供可复用的 RLVR+蒸馏融合机制，对 token 级信用分配有方法学贡献。

**可能影响：** 可能推动 RLVR 与 on-policy 蒸馏的进一步融合，影响数学推理模型的后训练策略。

## Emerging AI Concept

中文名称：智能体状态编辑世界模型  
英文名称：Agent-Editing World Model  
Emerging Score：8  
成熟度：Emerging

### 一句话理解

一种面向 LLM 智能体的世界模型新范式：不再预测环境观测或工具响应，而是建模推理与动作如何改变任务状态，并通过 Action Judge 与 State Revision 主动编辑历史中的噪声推理-动作延续，直接修正后续决策所依赖的状态。

### 为什么现在值得关注？

长程 LLM 智能体普遍受 task-state contamination 困扰，错误假设与过时计划在历史中累积并扭曲决策；同时真实工具反馈已足够廉价，模拟高熵工具响应价值有限，因此从'模拟环境'转向'编辑状态'成为更高效的世界模型方向。
