## 2. The End of Consensus Research?

AI Importance Score：7 / 10

**Facts：** 论文报告 AI 辅助发现新共识协议 A-greement，面向地理复制状态机，在 5 或 9 副本的六种部署上平均，写密集与读密集负载下相较最快基线分别降低平均延迟 12.2% 与 33.3%，只读负载持平。协议结合租约授权本地读、客户端直接获知领导者排序写、按网络拓扑与负载选择的快速固定法定人数逐键写路径。核心是 AI-greement agent harness，集成概念导向协议知识库、模块化实现骨架、基于 Lean 的验证框架（含可复用安全定义、参考规范与证明）。其 Lean 形式化发现现有共识协议若干未报告漏洞。作者强调人类共识专家在搜索前后仍不可或缺。

**Analysis：** 这是 AI 在分布式系统理论研究中产生可验证新成果的少见案例，关键不在于让通用编码 agent 自由发挥，而在于领域专用 harness（知识库+实现骨架+形式化验证）把搜索约束在可证明空间内。Lean 形式化发现既有协议漏洞，说明验证框架本身有独立价值。性能提升幅度中等但方向明确，人类专家仍处环路中。

**技术看点：** 展示“领域 harness + 形式化验证”将通用编码 agent 转化为科研工具的方法论，Lean 规范与证明可复用，对协议设计与验证自动化有较高参考价值。

**可能影响：** 可能改变分布式系统与形式化方法领域的研究流程，推动更多领域构建专用 agent harness；同时提示 AI 科研产出需人类专家把关。

## 3. Quant-Arena: Benchmarking LLM Agents for Quantitative Trading Research

AI Importance Score：6 / 10

**Facts：** 论文提出 Quant-Arena，面向真实 A 股数据的端到端量化研究基准与公开排行榜。模型构建特征与选股代码，仅获得 2022–2023 年反馈，冻结一个策略后在封存的 2024 年评估。现金账户评估器施加交易约束与成本，包括基于模拟订单簿估计的市场冲击。得分以已实现超额收益为主，辅以信号质量与特征多样性。评测九个前沿模型，GPT-6 Astra 得分最高，但无模型在 2024 年跑赢等权市场。排行榜开放任意模型或 agent harness 提交。

**Analysis：** 该基准把量化研究闭环（假设—实现—回测—决策）作为评测对象，并用封存年份与交易成本防止过拟合，设计较严谨。结果显示前沿模型尚不能稳定产生超越等权基准的策略，说明端到端量化研究仍是高难度 agentic 任务。局限是仅 A 股、单一年份封存，结论受市场状态影响。

**技术看点：** 提供带市场冲击模拟与交易约束的端到端评估框架及公开排行榜，可作为金融 agent 的可复现测试床，并暴露模型在样本外泛化上的短板。

**可能影响：** 为金融 LLM agent 评测建立更贴近实盘的基准，短期影响量化研究自动化工具选型，长期或推动 agent 在真实市场约束下的可靠性研究。

## 4. Multimodal Embodied Agents: A Unified Capability-centric Perspective from Computer-Use to Robot-Use

AI Importance Score：6 / 10

**Facts：** 论文定义多模态具身智能体（MMEA）为目标导向系统，将多模态任务推理与物理动作耦合，并根据反馈修正决策。提出 PAPAV 能力中心框架，含五项功能：感知状态、预期动作效果、规划可行路径、通过接口或身体行动、验证结果。按功能而非架构定义，用于比较 MMEA、多模态智能体（MMA）与机器人系统（RS）。指出五项物理约束（从部分可观测到结果不可验证）减少预先固定的选择与纠错空间。在 64 个基准中，显式评估集中在 Act，仅 5 个评估 Anticipate、3 个评估 Verify。

**Analysis：** 该综述的价值在于用统一能力框架把 computer-use 与 robot-use 放在同一坐标系下比较，并量化指出现有基准严重偏重“行动”而忽视“预期”与“验证”。这解释了具身 agent 在物理约束下可靠性不足的评测根源。局限是框架偏概念性，未提供新实验数据。

**技术看点：** PAPAV 可作为具身 agent 设计与评测的检查清单，揭示 Anticipate/Verify 评测空白，对构建可靠物理 agent 的基准设计有指导意义。

**可能影响：** 可能推动具身智能评测从任务成功率转向分能力度量，影响机器人基础模型与 computer-use agent 的评估标准。

## 5. Asymmetric On-Policy Distillation Learns In-Context Exploration

AI Importance Score：6 / 10

**Facts：** 论文提出 ASTEROID，一种学生—教师监督学习框架，用于学习测试时探索。特权专家无需探索，但历史条件化的学生在 on-policy 上下文中训练：学生先在部分可观测下收集 on-policy 上下文，特权专家基于该上下文给出动作标签。在十一个环境（离散探索基准、机器人操作、导航、Procgen）中，固定探索预算下回报约高 2 倍，交互次数比 RL 基线少约 100 倍，探索表现优于前沿模型。方法将仿真训练策略迁移到视觉受限的真实机器人操作，成功率较标准蒸馏提升 40%。

**Analysis：** 核心思路是用特权专家在学生的 on-policy 历史上打标签，从而把“探索行为”蒸馏进学生，绕开 RL 的样本低效与离线模仿的隐状态平均问题。与贝叶斯后验采样类比合理。实验覆盖广、真实机器人迁移是亮点。局限是依赖特权专家与仿真环境，真实场景特权信息获取成本需评估。

**技术看点：** 提供简单有效的探索学习范式，交互效率提升两个数量级，且可迁移到真实机器人，对具身策略学习与仿真到现实有实用价值。

**可能影响：** 可能降低学习探索行为的训练成本，推动机器人操作与部分可观测决策任务的落地。

## Emerging AI Concept

中文名称：模型共演化基准  
英文名称：LLM Co-Evolution Benchmark  
Emerging Score：7  
成熟度：Emerging

### 一句话理解

以模型互相生成环境、互相求解并量化彼此影响的方式，评测模型作为创作者与求解者的双重能力，并观察排名传递性、设计收敛与训练迁移等生态现象。

### 为什么现在值得关注？

前沿模型越来越多地吸收彼此与网络合成数据，自博弈与合成环境成为训练关键环节，但缺乏可控、可复现的度量框架；Environment Duels 与 Quant-Arena 等基准同期出现，标志评测从单任务分数转向生态互动。
